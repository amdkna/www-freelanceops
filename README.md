# FreelanceOps

FreelanceOps is a client operations platform for freelancers managing multiple websites, domains, SSL certificates, renewals, monitoring, and recurring operational responsibilities.

## Current MVP

The current MVP is focused on a single freelancer who wants to:

- monitor website availability
- track domain expiration dates
- track SSL certificate expiration dates
- receive Telegram alerts and reminders
- keep outage history
- see all monitored websites in one central view

## Documentation Rule

Whenever a new document is added under `/docs`, this root `README.md` must also be updated in the same change.

The new document must be added to the Documentation section with:

- a relative link
- the document name
- a short description explaining what the document is for

This keeps `README.md` as the main index for all project documentation.
